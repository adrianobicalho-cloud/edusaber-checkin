# Lista de Presença - EduSaber 2026

Sistema de controle e registro de presença para o evento EduSaber 2026. Clonado e adaptado da aplicação interativa.

## 🚀 Funcionalidades

- **Check-in de Participantes**: Registro de presença com nome, email, telefone, cargo/instituição e quantidade de acompanhantes.
- **Painel Administrativo**:
  - Listagem em tempo real de participantes confirmados.
  - Indicadores e estatísticas gerais (total de presenças, acompanhantes, taxa de comparecimento).
  - Filtros e busca por nome ou instituição.
  - Exportação de dados (CSV / Excel).
- **Design Moderno e Responsivo**: Desenvolvido com Tailwind CSS e ícones Lucide.

## 🛠️ Tecnologias

- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React**

## 💻 Como Executar

1. Instalar as dependências:
```bash
npm install
```

2. Iniciar o servidor de desenvolvimento:
```bash
npm run dev
```

3. Construir para produção:
```bash
npm run build
```
