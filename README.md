# Edusaber Check-In

criar um aplicativo para lista de presença, onde o participante registra sua presença, peça para o participante os segintes dados:

-nome completo

-quantas pessoas o acompanham no evento (opções de marcar: 1,2,3,4,5,6)

-não aceite repetição de mesmo nome

-colocar botão enviar para registrar a presença e contabilizar os visitantes

-no final retornar a mensagem: AGRADECEMOS SUA VISITA! ( COM O LOGO DA FEIRA)

Também crie um campo de administrador com a senha 1234, para que o admin possa acompanhar todos os dados registrados, traga na dashboard na tela a opção de baixar um arquivo em xlsx ou csv.

Seguindo o padrão de letras e textos do logo em anexo assim como sua paleta de cores.

-título: LISTA DE PRESENÇA FEIRA EDUSABER 2026
-após a mensagem de agradecimento pela presença, colocar a logo no centro e um botão fechar( para encerrar o aplicativo)
